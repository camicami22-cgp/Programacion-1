
# Programacion 1

Este repositorio contiene los programas y ejercicios desarrollados durante la materia de Programacion 1.

## Programas incluidos

### IMC
Programa que calcula el IMC del usuario.

### Calificaciones
Programa que calcula el promedio deseado del usuario.

### CURP
Programa que obtiene datos del usuario y los convierte en su CURP.

### Figuras
Programa que obtiene una cantidad deseada del usuario y los convierte en figuras elegidas por el usuario.

### BlackJack
Programa que crea un juego de cartas llamado BlackJack.
